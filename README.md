# Läkemedelsberäkning – tre vägar till samma svar

Formelmetoden, proportionsmetoden och dimensionsanalys

Michael Ulrich Hansen

## Publicera på GitHub Pages

1. Packa upp ZIP-filen.
2. Lägg innehållet i mappen lakemedelsberakning-github-pages i roten av ditt GitHub-repository. index.html ska ligga direkt i roten. Ta med assets-mappen och samtliga HTML- och JS-filer.
3. I repositoryts Settings → Pages väljer du Deploy from a branch, grenen main och / (root). Spara.

Ingen installation eller byggprocess behövs. Tentamensläget och blandad träning bör öppnas via webbplatsens adress; direktöppnade lokala filer kan begränsa kommunikationen mellan sidorna.

## Innehåll

14 övningsområden, blandad träning och tentamensläge med tio frågor och uppföljning. Samtliga områden ingår utan nivåval. Äldre länkar till blandad_tentatraning.html leder till gemensam blandad träning.

Startsidan finns som index.html och lakemedelsberakning_ny_startsida.html. assets innehåller den gemensamma formgivningen. Ursprungliga uppgiftsgeneratorer och svarskontroller ligger kvar i respektive HTML-fil. exam_bridge.js innehåller den befintliga tentamenskopplingen och metodvisningen. kvalitetskontroll.html från originalappen följer med.

Källa: https://github.com/michaelulrichhansen/Lakemedelsberakning (hämtad 2026-09-05). Uppgiftskod och exam_bridge.js har bevarats. Integrationens kontroller är tekniska och utgör ingen ny sakgranskning av uppgifterna.
